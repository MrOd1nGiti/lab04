# Лабораторная работа 4. Циклы, счётчики и накопители

## Запуск программ
Каждая программа запускается через терминал:
- python range_numbers.py
- python statistics.py
- python positive_input.py
- python variant.py

---

## Таблица значений (сумма чисел от 1 до 4)
| Шаг цикла (number) | total до прибавления | total после прибавления |
|---|---|---|
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |
| 4 | 6 | 10 |

---

## Проверки и результаты

### 1. Диапазон в обе стороны (range_numbers.py)
- Входные данные: 2, 4 -> Результат: 2, 3, 4 (каждое на новой строке)
- Входные данные: 4, 2 -> Результат: 4, 3, 2 (каждое на новой строке)
- Входные данные: 3, 3 -> Результат: 3

### 2. Статистика потока (statistics.py)
- Входные данные: n=3, числа -5, -2, -8 -> Сумма: -15, Положительных: 0, Максимум: -2
- Входные данные: n=1, число 0 -> Сумма: 0, Положительных: 0, Максимум: 0

### 3. Повторный ввод (positive_input.py)
- Входные данные: 0, -2, 3 -> Квадрат: 9, Отклонено попыток: 2

### 4. Индивидуальный вариант 1: Чётные числа и простота (variant.py)
- Входные данные (контрольный набор n=7): -12, -3, 0, 2, 10, 15, 20 -> Количество чётных: 5, Сумма чётных: 20
- Входные данные (n=0): цикл не выполняется, количество 0, сумма 0
- Дополнительная проверка на простоту:
  - 2 -> простое
  - 9 -> составное
  - 17 -> простое
  - 49 -> составное
